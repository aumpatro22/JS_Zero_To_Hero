## Roadmap

- Strengthen JavaScript fundamentals
- Add DOM and browser API practice
- Build small interactive projects
- Practice async JavaScript and fetch requests
- Keep publishing progress consistently

## Current workflow

I use a small helper script to publish progress to GitHub.

```bash
node publish.js
```

The script asks what you worked on, builds a commit message, adds your changes, commits them, and pushes to GitHub.

## How to run code

Most files can be executed with Node.js:

```bash
node Day-0/basic.js
```
